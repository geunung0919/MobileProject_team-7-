# AI 없는 음식 검색 추가

기준: 앞서 전달한 git-ui-fridge-snack (Git UIUX 기준, 로그인 없음).
GitHub 및 Snack 원격 저장소는 변경하지 않았습니다.

## 추가/변경 파일 (source 폴더 기준)
| 파일 | 변경 내용 |
|---|---|
| module3/data/seed.js | 토마토 스파게티 1인분 레시피 추가: 스파게티면 100g, 토마토소스 150g, 마늘 10g, 올리브유 10ml / 냄비·프라이팬 / 20분 / 조리 순서 |
| module3/domain/recipeSearch.mjs | 요리명·재료 검색에 별칭 검색 추가. 파스타로도 스파게티 검색 |
| integration/recipes.mjs | 필요량 대비 사용 가능한 재고·부족량 계산 및 단위 불일치 표시 |
| src/screens/FridgeScreen.js | 레시피 검색·추천 버튼과 음식 검색 메뉴 연결 |
| src/screens/RecipeListScreen.js | 검색창 기본 표시. 검색 모드에서는 재고·도구·추천 조건으로 검색 결과를 숨기지 않음 |
| src/screens/RecipeDetailScreen.js | 도구 목록, 미보유 도구, 재료별 필요/보유/부족량 표시. 충분하면 조리 화면, 부족하면 장보기 추가. 도구 부족은 설정으로 연결 |
| module3/app/recipe/[id].js | 검색에서 선택한 레시피의 실제 사용량 확인 흐름 연결. 완료 버튼을 조리 완료·확인 후 차감으로 표시 |
| tests/foodSearch.test.mjs | 검색 별칭·빈 재고·부분 부족·단위 불일치·만료 재고·조회 무변경 테스트 4개 추가 |
| App.js | 위 소스를 반영해 Snack용 단일 파일 재생성 |

기존 장보기 부족 수량 추가, 실제 사용량 입력, atomic 차감, 저장 실패 처리, 중복 차감 방지, 되돌리기는 기존 기능을 재사용합니다.
AI/API 호출과 서버 저장은 추가하지 않았습니다. 총 5개 등록 레시피만 검색합니다. 재료명과 단위가 같은 재고만 합산하며 임의 환산은 하지 않습니다. 검색 별칭과 재고 재료명 매칭은 별개입니다.
검색에서는 추천 조건으로 메뉴를 숨기지 않습니다. 상세에 필요한 도구를 안내하고 보유 도구 설정 확인 후 조리를 시작합니다. 검색 결과는 알레르기 안전 판정이 아니므로 재료를 직접 확인해야 합니다.

## 실행
기존 Snack을 사본으로 저장한 후 SDK54에서 snack/package.json과 snack/App.js 전체를 각각 교체합니다.
냉장고 → 레시피 검색·추천 → 스파게티 검색 → 상세 확인.
처음에는 스파게티 재료가 없으므로 부족량이 표시됩니다. 재료를 정확한 이름·단위로 등록하고 조리 도구 설정에 냄비와 프라이팬을 선택하면 요리 시작 버튼이 표시됩니다.
요리 시작 → 실제 사용량 수정 → 조리 완료·확인 후 차감 → 되돌리기.
검색과 시작 버튼만으로는 재고가 차감되지 않습니다.

분리 소스는 source 폴더에 있습니다. 팀 코드에는 생성된 거대한 App.js 대신 분리 소스의 변경 파일을 검토하여 반영하세요.
