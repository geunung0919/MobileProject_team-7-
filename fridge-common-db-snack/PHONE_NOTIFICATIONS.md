# 폰에서 유통기한 임박 알림 받기

이 파일이 이번 버전의 실행 안내입니다. 과거 변경 문서의 '재고 알림은 화면 데모' 설명을 대체합니다. 레시피 알림 화면은 아직 기존 데모입니다.

## 적용 및 테스트
1. Snack SDK54에서 snack/package.json을 먼저 전체 교체합니다. expo-notifications ~0.32.12가 추가됐습니다.
2. snack/App.js를 전체 교체하고 Save합니다.
3. My Device의 QR을 실제 휴대폰 Expo Go로 엽니다. 설치된 Expo Go가 SDK54를 지원해야 합니다. 호환되지 않으면 호환 환경 또는 개발 빌드가 필요합니다.
4. 냉장고 → 보관 중인 식재료 옆 ··· → 날짜 알림.
5. 60초 후 테스트 알림을 누르고 폰의 알림 권한을 허용합니다.
6. '예약했어요' 메시지 확인 후 홈 버튼으로 앱 밖으로 나가고 폰을 잠급니다. 약 60초 뒤 알림을 확인합니다. 테스트는 재고 유무와 무관합니다.
7. 테스트 알림을 누르면 냉장고 첫 목록으로 이동합니다. 테스트 취소 버튼도 있습니다.

## 실제 재고 날짜 예약
날짜 알림 화면에서 재고 알림 사용을 켜고 3일 전/1일 전(필요하면 7일 전/당일)과 시·분을 선택한 뒤 저장/예약 다시 확인을 누릅니다.
예약 N건을 확인하세요. 이미 지난 시각은 새로 예약하지 않습니다. 오늘 날짜로 테스트한다면 '당일'을 선택하고 현재보다 뒤의 시각으로 지정하세요.
재료의 날짜 변경·삭제·전량 사용·되돌리기 후 예약을 갱신합니다. 앱 재실행/복귀 시에도 갱신합니다. 재고는 현재 기기 내부 데이터 기준이며 서버 동기화 알림은 아닙니다.
날짜를 안전 판정으로 사용하지 않으며 참고일과 표시기한을 구분합니다. 기본 3일 전·1일 전 오전9시, 기기 시간대를 사용합니다.

## 수신 조건과 한계
OS에 예약하는 로컬 알림입니다. 서버·AI·푸시 토큰이 필요하지 않습니다. Expo 공식 문서에서 로컬 알림은 Expo Go 지원, Android SDK53 이후 원격 푸시는 개발 빌드 필요로 구분합니다.
https://docs.expo.dev/versions/latest/sdk/notifications/
휴대폰 알림 설정에서 Expo Go 또는 개발 앱의 잠금화면/배너/소리를 허용하세요. 무음·집중모드·배터리 제한·제조사 설정 등에 따라 표시·소리·시각이 달라질 수 있습니다. Android 설정의 강제 종료는 일반적인 홈 화면 이동과 다르며 수신을 막을 수 있습니다.
정각 도착이나 항상 울리는 알람시계 기능을 보장하지 않습니다. 기기 재부팅 후 앱을 열어 예약을 다시 확인하세요. 시간대 변경도 앱 복귀 때 갱신됩니다.
기기 예약 개수 한도 때문에 가까운 알림부터 예약하고 미예약 건수를 표시합니다.
배포용 개발 빌드에서는 source에서 npm install, npx expo install expo-notifications 후 팀 빌드 절차를 사용하세요. app.json에는 expo-notifications 플러그인을 추가했습니다. 실제 기기에서 최종 검증해야 합니다.

## 변경 파일(source 기준)
- module3/services/inventoryNotifications.js / .native.js: 실제 날짜 예약, 권한, Android 채널, 소리, 60초 테스트/취소, 알림 클릭 처리.
- module3/services/inventoryNotifications.web.js: 웹 지원 불가 안내.
- integration/InventoryNotificationObserver.js: 재고/설정 변경 및 앱 복귀 때 예약 갱신, 예약 오류 표시, 알림 클릭 시 냉장고 복귀.
- IntegrationApp.js: 관찰 컴포넌트 연결.
- module3/app/inventory/alerts.js: 실제 폰 테스트/취소 버튼 추가.
- package.json, snack-package.json, app.json: 패키지와 네이티브 설정.
- tests/nativeAlerts.test.mjs: OS 예약 API 모형으로 테스트 알림 유지/취소 및 웹 미지원 검증.
- App.js: Snack 단일 파일 재생성.

## 확인 범위
자동 테스트58개 통과, Snack 단일 파일 생성 성공. 실제 기기 수신은 아직 검증하지 않았습니다. 이번 버전의 Expo Web export는 미검증입니다. 테스트용 API 모형은 실제 폰 수신 검증을 대체하지 않습니다.
GitHub 및 사용자 Snack 원격 파일은 변경하지 않았습니다.
