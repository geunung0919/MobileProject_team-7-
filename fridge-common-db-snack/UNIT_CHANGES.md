# 재고 단위 자동 맞춤 수정

AI/API 없이 기존 음식 검색 버전에 추가했습니다. Git/원격 Snack은 수정하지 않았습니다.

- 밥/쌀밥/흰밥 입력 시 공기, 달걀/계란 입력 시 개, 김치/스파게티면/토마토소스/마늘은 g, 올리브유는 ml, 두부는 모를 제안합니다.
- 새 식재료 이름을 입력하면 기준 단위가 자동 선택됩니다. 사용자가 단위를 직접 선택한 뒤에는 기본 입력 화면에서 자동으로 덮어쓰지 않습니다.
- 단위 선택 목록에 공기를 추가했습니다.
- 저장 시 kg→g, L→ml는 수량도 1000배 변환하고 금액은 유지합니다.
- 쌀밥/흰밥→밥, 계란→달걀로 저장 이름을 통일합니다. 등록된 정확한 별칭만 처리합니다.
- 개/봉/병 등의 무게나 밥 한 공기의 중량을 추측하지 않습니다. 기준과 다른 단위는 안내하고 직접 선택하도록 합니다.
- 기존 밥 1개는 자동 변경하지 않습니다. 목록의 밥을 선택→공기 단위로 변경→실제 수량 확인→수정 완료를 누르면 됩니다.

## 변경 파일 (source 기준)
module3/domain/foodUnits.mjs: 재료별 기준 단위/이름과 정확한 단위 환산 함수 추가.
module3/domain/inventoryFields.mjs: 저장 검증 직전 공통 단위·재료명 표준화.
src/data/fridge/fridge.js: 공기 단위 옵션 추가.
src/screens/FridgeAddScreen.js: 이름에 따른 자동 선택, 단위 차이 안내, 기존 재고 수정 버튼, 환산 미리보기.
module3/components/InventoryForm.js: 상세 관리 폼에도 단위 제안·수정 연결.
tests/foodUnits.test.mjs: 제안/환산/비환산/금액 보존/레시피 매칭 테스트 추가.
App.js: Snack 실행용 재생성.

## 적용
SDK54에서 snack/package.json과 snack/App.js 내용으로 교체합니다. source는 수정용 원본입니다.
기존 저장 데이터를 지우지 않습니다. 별도 Snack에서는 기존 데이터가 보이지 않을 수 있습니다.

자동 테스트 56개 통과, Expo Web 빌드 성공. 실제 Snack/휴대폰 조작은 미검증입니다.
