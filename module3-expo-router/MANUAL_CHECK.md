# 수동 확인 순서
1. 재고 등록: 달걀 6개, 구매 금액 3000원, 오늘 구매, 냉장, 포장지 표시 소비기한, 미래 날짜 입력 후 저장.
2. 수정 화면을 다시 열어 입력값 유지 확인. 밥 2공기도 추가.
3. 레시피에서 달걀 덮밥 → 요리 시작 → 달걀 사용량을 1개로 수정 → 확인 후 차감.
4. 달걀 5개/2500원 및 식사 기록을 확인. 되돌리기로 6개/3000원과 식사 취소 확인.
5. 달걀 폐기하기 → 2개 입력 → 폐기 금액 1000원, 잔여 4개/2000원 확인 → 확인 후 폐기.
6. 앱을 재실행하고 재고 목록에서 되돌리기 → 6개/3000원과 폐기 기록 취소 확인.
7. 7개 폐기, 음수/빈값/문자 사용량을 입력하면 차감 버튼 비활성화 또는 오류가 나오는지 확인.
8. 차감 후 다른 재고를 수정하면 이전 되돌리기 버튼이 없어지는지 확인.
9. 금액 미입력 재고는 사용/폐기 시 금액 미입력으로 표시되는지 확인.
10. 지난 날짜의 재고는 자동 삭제되지 않고 폐기는 가능하지만 요리 차감에서는 제외되는지 확인.
11. 추천 탭에서 임시 추천 안내, 재고가 전혀 없을 때 등록 안내 확인.

## 검색·장보기·예약 알림 (2026-10-30)
1. 레시피 탭에서 `계란` 입력 → 달걀 요리 검색. `두부 김치` → 두부 김치 표시. 없는 이름 → 결과 없음, 초기화 가능.
2. 재고 없는 상태에서도 전체 카탈로그 표시, `현재 재고로 가능한 요리만`을 켜면 0개. 시간 필터와 정렬 확인.
3. 두부 김치 상세 → 부족 재료 장보기 추가 두 번 → 중복 누적 없음. 장보기에서 수량 수정 후 앱 재실행 → 유지.
4. 쿠팡 검색 버튼 → 해당 재료 검색 URL 열림. 구매 완료 상태는 자동 변경되지 않음.
5. 구매 완료 → 재고 등록 → 수량·단위 미리 채움 확인 → 날짜/보관방법을 입력해 저장 → 재고 1건 추가, 장보기 등록 완료.
6. 같은 품목 재등록 및 삭제된 항목의 오래된 등록 화면은 거부. 등록 후 되돌리기 이전 기록은 무효화.
7. Android/iOS에서 알림 권한 거부 → 오류 안내, 실제 예약 없음. 설정에서 허용 후 2분 뒤로 예약.
8. 앱이 열린 상태 및 백그라운드에서 수신 확인. 알림 탭 → 해당 레시피. 앱을 종료한 상태에서 탭해도 정상 이동, 재실행 시 같은 알림으로 반복 이동하지 않음.
9. 같은 레시피를 다른 시각으로 재예약 → 예약 1개. 취소 → 실제 예약 목록에서도 제거. 앱 다른 모듈 알림은 유지.
10. 매일 알림 설정 후 목록 표시, 오늘보다 지난 시각의 1회 알림은 내일로 설정되는지 확인.
11. 웹에서 알림 화면 → 미지원 안내(권한 프롬프트/오류 루프 없음). 검색과 장보기는 정상.
12. 기존 실제 사용량 차감/되돌리기/일부 폐기 흐름 회귀 확인.

위 실기기 항목은 실행 안내이며 이 환경에서 실수신 완료로 주장하지 않습니다.
