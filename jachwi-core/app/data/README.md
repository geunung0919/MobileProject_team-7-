# 법정동 코드 데이터 (`legal_dong.json`)

- 내용: 현재 존재하는 시도·시군구·읍면동(리 제외)의 법정동 코드와 이름. 거주 지역 검색·저장(AC-08, AC-09)에 사용.
- 원본: 행정안전부 행정표준코드관리시스템(code.go.kr) **법정동코드 전체자료**, 2026-09-29 기준 스냅샷.
  - 공식 사이트에서 직접 내려받지 못해, 같은 형식(법정동코드·법정동명·폐지여부)의 공개 저장소 사본
    (`prgrms-be-devcourse/NBE11-13-final-Team02` 의 `legal_dong_20260929.csv`)으로 만들었다.
  - 공공데이터포털 '국토교통부_전국 법정동'(2026-06-30, 20,561행)과 존재 코드 수(20,560)가 거의 같음을 확인했다.
  - 반영 확인: 강원·전북특별자치도, 대구 군위군, 전남광주통합특별시, 인천 제물포구·영종구·서해구·검단구, 화성시 일반구.
- 라이선스: 공공누리 제1유형(출처표시) — 출처: 행정안전부.
- 갱신: code.go.kr 에서 최신 전체자료를 받아 `python scripts/build_legal_dong.py <파일> <기준일>` 실행.
  앱(`UIUX/src/data/regions/legalDong.json`)과 서버 파일이 함께 갱신된다. **발표 전 공식 원본으로 한 번 다시 만드는 것을 권장.**
