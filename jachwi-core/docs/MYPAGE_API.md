# 마이페이지 · Expo 연결 가이드

## 개발 환경

앱은 React Native + JavaScript + Expo, 서버는 Python + FastAPI + Pydantic입니다.
현재 DB 검증은 SQLite 기준이며 MySQL 실서버 검증은 별도입니다.
`feature/fintech-basic` 기반으로 기존 온보딩·소비 API를 유지합니다.

## 이번 추가: 알림 선호 설정

| 동작 | API | 응답 |
| --- | --- | --- |
| 화면 진입 / 재시도 | GET /api/v1/me/notification-settings | 아래 설정 JSON |
| 저장 버튼 | PUT /api/v1/me/notification-settings | 저장 완료된 설정 JSON |

기존 개발 Bearer 토큰을 사용합니다. 사용자 ID는 요청에 넣지 않습니다.

```json
{
  "spending_alerts": true,
  "inventory_alerts": false,
  "routine_reminders": true
}
```

- 각각 소비·예산 알림, 재고 알림, 생활 루틴 알림의 선호 설정입니다.
- 저장 이력이 없으면 모두 false로 반환합니다. GET은 데이터를 생성하지 않습니다.
- PUT은 세 필드를 모두 보내는 전체 교체입니다. boolean만 허용하며 누락·문자열·숫자는 422입니다.
- 실패하면 이전 설정을 유지합니다. 다른 사용자 설정은 조회하거나 바꿀 수 없습니다.
- 온보딩 수정이나 앱 재시작으로 설정을 초기화하지 않습니다.
- 동시 편집은 마지막 성공 저장이 반영됩니다. 충돌 감지는 후속 범위입니다.
- 새 테이블 core_notification_settings가 개발 서버 시작 시 생성됩니다. 기존 테이블은 변경하지 않습니다.

## 4번 화면 담당에게 전달할 동작

현재 mobile/src/lib/api.js의 createApi를 통해 아래처럼 호출할 수 있습니다.

```js
const saved = await api('me/notification-settings');
// saved의 복사본으로 토글을 편집한 다음 저장 버튼에서 호출
const result = await api('me/notification-settings', 'PUT', draft);
```

조회 실패 시 모두 OFF로 표시하고 덮어쓰지 말고 재시도 화면을 표시합니다.
조회 중에는 토글/저장을 비활성화합니다. 저장 중 중복 요청을 막습니다.
저장 성공 후에만 완료 메시지를 보여주고, 실패하면 편집값을 유지합니다.
취소 시 저장 API 없이 편집본을 버립니다.

이 값은 **OS 알림 권한, 푸시 토큰, 예약/발송 여부가 아닙니다.**
Expo의 /mypage 화면에 토글·저장·취소·조회 재시도를 연결했습니다. 실제 알림 발송은 미구현입니다.
실제 알림 기능은 발송/예약 전에 이 설정을 확인해야 합니다. 설정 변경 후 기존 로컬 예약의 취소·재등록도 기기 담당이 구현해야 합니다.

## 기존 마이페이지 기능 연결

생활 설정 조회/재진단은 기존 GET/PUT me/onboarding과 POST me/onboarding/preview를 사용합니다.
온보딩 목표 예산 변경은 소비 모듈의 실제 월 예산을 자동 변경하지 않습니다.
실제 계정 정보, 소셜 로그인, 재인증 탈퇴는 이번 범위에 포함되지 않습니다.

## 실제 기기 확인 순서 (아직 미실시)

1. 새 서버 실행 후 Expo 앱 연결 → 소비 관리 → 마이페이지로 이동합니다.
2. 알림 설정을 변경하고 취소한 뒤 다시 진입해 기존 설정이 유지되는지 확인합니다.
3. 설정을 저장한 뒤 앱 재연결 후 저장값이 유지되는지 확인합니다.
4. 서버를 중지한 상태에서 조회하면 토글 대신 오류/재시도가 나오는지 확인합니다.
5. 조회 후 서버를 중지하고 저장하면 성공 메시지 없이 편집값과 오류가 남는지 확인합니다.
6. 서버를 다시 시작하고 저장을 재시도합니다.
7. 생활 설정 확인·수정 → 미리보기 → 저장/취소 시 마이페이지로 돌아오는지 확인합니다.
8. 다른 개발 사용자로 연결해 설정이 분리되는지 확인합니다.

2026-10-07 서버 회귀 테스트: 43개 통과 (Python 3.12 / SQLite).
