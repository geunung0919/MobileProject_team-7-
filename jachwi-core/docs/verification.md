# 검증 기록

검증 환경: Linux / Python 3.12 / SQLite. Windows와 MySQL 실서버 검증은 미실시.
자동 테스트: 16개 통과.

- 인증 없는 요청 거부, 사용자 A/B 데이터 분리
- 미입력/null과 0원/빈 재고 구분
- 잘못된 금액, 범위, 중복 조리도구, 임의 user_id 거부
- 스냅샷 재전송 허용, 과거/동일시각 상충 데이터 거부
- 미래 시각 및 timezone 누락 거부
- 오래된 자료와 이전 월 예산을 최신 정보에서 제외
- AI 입력에서 불필요한 거주 지역 제거
- 한국 날짜 기준 D-Day와 추정 날짜 표시
- 재시작 후 프로필 보존, 개발 쓰기 API 비활성화 확인
- 재고/루틴 입력에서 홈 조회까지 연결

테스트 라이브러리의 deprecation 경고 2건이 있었으나 테스트는 통과했습니다.

실제 Uvicorn HTTP 서버에 examples/demo.py 실행 성공: 예산 초과·계란 D-1·분리배출 카드 3개 확인.
